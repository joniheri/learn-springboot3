# Sintak Git

- `git branch -d <nama_branch>` --> Menghapus Branch local yang Sudah Di-Merge (Aman):
- `git branch -D <nama_branch>` --> Menghapus Branch local yang Belum Di-Merge (Hati-hati)
- `git push <nama_remote> --delete <nama_branch_remote>` --> Menghapus branch server (branch yang ada di server remote seperti GitHub, GitLab, Bitbucket)
